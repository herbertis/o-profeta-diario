# 📰 O Profeta Diário

Landing page temática inspirada no universo de Harry Potter, desenvolvida com HTML5, CSS3 e JavaScript, simulando a versão digital do icônico jornal bruxo.
--
## 🔗 Acesse o projeto:
https://herbertis.github.io/o-profeta-diario/

--

## 🎯 Objetivo do Projeto

Criar uma experiência imersiva inspirada no jornal mágico do universo Harry Potter, aplicando:

Estrutura semântica em HTML5

Layout editorial responsivo

Interações dinâmicas com JavaScript

Identidade visual temática

O projeto simula uma edição digital interativa do jornal, equilibrando estética, usabilidade e organização de conteúdo.

--

## ✨ Funcionalidades

🎩 Layout editorial inspirado em jornais clássicos

🧙‍♂️ Matérias fictícias com imagens, GIFs e animações

🌙 Alternância de tema (modo claro/escuro)

📱 Design totalmente responsivo (desktop, tablet e mobile)

🎬 Elementos visuais que reforçam a atmosfera mágica

📰 Destaques de Conteúdo

🏆 Harry Potter descobre um novo Pomo de Ouro

🏰 Nova direção em Hogwarts

🏦 Promoções em Olivaras e Gringotts

🚂 Festival de Hogsmeade com desconto no Expresso de Hogwarts

🖤 Especial sobre Sirius Black, Família Black e Bellatrix Lestrange

--

## 🛠 Tecnologias Utilizadas

✅ HTML5 – Estruturação semântica e organização de conteúdo

🎨 CSS3 – Grid layout, responsividade e estilização personalizada

⚙️ JavaScript + jQuery – Interações e manipulação de DOM

🔤 Google Fonts – Tipografia temática

🧩 Simple Line Icons – Biblioteca de ícones

--

## 🧠 Conceitos Aplicados

Estrutura modular de layout

Organização editorial com grid

Hierarquia visual

UX focada em leitura

Alternância dinâmica de tema

Responsividade mobile-first
